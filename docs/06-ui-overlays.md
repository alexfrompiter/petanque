│  ⚙  Petanque                       ❄ 📸 │  ← top bar:

## Слои (toggle independently)

| Слой | Описание | По умолчанию |
|---|---|---|
| `bbox` | Контур вокруг каждого шара и кошонета. Цвет по классу. | вкл |
| `labels` | Номер ранга (1, 2, 3…) над шаром. Цифра в кружке. | вкл |
| `distances` | Текст «1.23 м ±0.05» рядом с шаром. | вкл |
| `lines` | Линии от центра кошонета к центру каждого шара. | вкл |
| `circles` | Окружности на плоскости земли вокруг кошонета. Радиусы: радиус ближайшего шара, ½×, 2×. | выкл |
| `arDebug` | Точки feature points + плоскости от ARKit/ARCore. | выкл |
| `quality` | Индикатор качества + подсказка снизу. | вкл |
| `teams` | (этап 2) подсветка по командам по цвету. | — |

Все слои сохраняются в `UserDefaults` / `SharedPreferences` и
восстанавливаются при запуске.

## Цвета и стиль

- Кошонет: **жёлтый** контур + жёлтая точка-метка.
- Шары: **белый** контур (фон оверлея — поверх любой картинки), номер в
  тёмном круге с белой цифрой.
- Шар №1 (ближайший): **зелёный** контур.
- Шар-победитель (если есть однозначный): **толстый зелёный** контур + 🏆.
- Линии: полупрозрачные белые, толщина 2 pt.
- Окружности на земле: проецируются через камеру с учётом перспективы
  (рисуется как эллипс).

Контрастность важна: оверлей рисуется на любой картинке (песок, гравий,
тень) — везде должен читаться. Используем тонкий тёмный outline под белым
текстом.

## Подсказка и индикатор качества

Bottom card показывает:
- одну активную подсказку (приоритет по тяжести проблемы, см. таблицу в
  `04-distance-estimation.md`),
- 5-точечный индикатор качества (от 0–20: ●○○○○ до 80–100: ●●●●●),
- крошечную плашку с числом найденных шаров и кошонета.

Если качество ≥ 80, баннер сворачивается до тонкой полоски «Готово».

## Заморозка кадра (frozen mode)

При тапе на ❄:
- последняя `SceneState` фиксируется,
- камера продолжает работать, но оверлей не обновляется,
- появляется кнопка ▶ «продолжить» и 📤 «поделиться скриншотом».

Полезно для разрешения спорных моментов: «вот, смотри, по моему телефону
1.23 vs 1.31 — мой шар ближе».

## Настройки (settings sheet)

Открывается тапом на ⚙. Секции:

1. **Слои.** Тогглы из таблицы выше.
2. **Размеры шаров.** Диаметр boule (default 74 мм, slider 70.5–80) и
   cochonnet (default 30 мм, slider 28–32). Действуют для геометрии-метода.
3. **Единицы измерения.** Метры/см vs футы/дюймы.
4. **Производительность.** Авто / экономия батареи (15 FPS) / макс. точность
   (30 FPS, нагрев).
5. **Отладка.** Включить `arDebug`, показать FPS-счётчик, лог дистанций.
6. **О приложении.** Версия, модель ML, ссылка на правила петанка.

## Пустые состояния и ошибки

| Состояние | Что показываем |
|---|---|
| AR ещё не нашёл плоскость | Полупрозрачный overlay по центру: «Помашите телефоном медленно для калибровки AR» + анимация |
| Кошонет не найден | Подсказка «Тапните по кошонету» — пользователь указывает вручную, мы засчитываем эту детекцию вручную |
| Нет шаров | «Никаких шаров не вижу — наведите камеру на площадку» |
| Камера запрещена | Кнопка «Открыть настройки» |
| Слишком темно | «Слишком темно — включите фонарик?» (с кнопкой) |

## Доступность

- Минимальный target hit area 44×44 pt.
- Все цвета должны иметь альтернативу для дальтоников (используем shape, а
  не только цвет — кошонет всегда квадратная метка, шары круглые).
- Большие шрифты — поддержка Dynamic Type / Material font scale.
- VoiceOver / TalkBack: озвучиваем дистанции и ранги при тапе на шар.
